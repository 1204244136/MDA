# MDA 票券生成器

在仓库根目录运行：

```powershell
go -C agent\go-service run ./cmd/ticket-generator -out-dir C:\Tickets
```

生成器支持常规额度重置券、专项额度重置券和活动额度发放券。原 `cmd/quota-refill-generator` 已更名为 `cmd/ticket-generator`。

活动额度发放券需输入时长（整数分钟），可选限定任务入口，例如 `MapPushingFlow`、`EquipmentRerollMain`、`CustomBurstMain`；留空适用于全部计时任务。入口取自 `assets/tasks/*.json` 的 `entry`，须保持大小写一致。

常规额度按北京时间每日凌晨 4 点刷新，专项额度按会员订阅周期计算；重置券只清零对应额度的已用量，不增加档位额度或延长订阅周期。活动额度发放券按指定时长新增额度。

输入兑换有效天数和可选设备赞助链接后，会生成独立 `.exe` 票券。用户在目标设备运行并按回车兑换，即可向该设备的本地额度记录添加活动额度，无需会员订阅。相同票券在该设备只能兑换一次，不同票券可叠加。赞助链接留空时，每台设备均可兑换一次。

消费顺序为：匹配当前任务的活动额度 → 专项额度（适用的高级任务）→ 常规额度。同为活动额度时先用限定任务的额度，再用不限任务的额度。活动及专项额度按实际时长扣减；高级任务转用常规额度的部分按 5 倍扣减。

票券兑换有效期限制兑换日期；兑换后的活动额度没有到期日，不随每日重置、会员档位或会员周期改变。原有重置券不会重置或清除活动额度。「额度显示」任务可查看剩余活动额度及其任务范围。
