# NIKKE 装备系统与洗词条研究

> 面向 agent 的知识底稿，服务于 MDA 的"洗装备词条"自动化任务。

- 整理日期：2026-08-19
- 整理依据：Prydwen 公开攻略 + BiliGame NIKKE wiki 检索 + 游戏内截图核对（详见[来源与更新说明](#来源与更新说明)）
- 适用范围：NIKKE 游戏，简体中文界面（MDA 仅适配中文 UI）
- 状态：已根据游戏内截图核对主要 UI 文案；概率、数值池和成本细节仍以实际客户端为准

## 一句话结论

NIKKE 的“洗装备词条”只指对 **T10 装备**反复重随随机效果，不包括提升装备强化等级，也不包括把 T9 企业装改造为 T10 装备。普通装备（T1~T9）没有随机效果，不能洗词条。

## 概念边界

装备强化、T9 → T10 改造、洗词条和洗数值是四个不同操作，后续设计任务时必须分别建模：

| 概念          | 操作对象                                  | 主要操作                                 | 直接结果                                        | 是否属于洗词条   |
| ------------- | ----------------------------------------- | ---------------------------------------- | ----------------------------------------------- | ---------------- |
| 装备强化      | 普通装备或 T10 装备                       | 消耗强化材料，提高装备强化等级           | 提高装备自身的基础属性                          | 否               |
| T9 → T10 改造 | 已强化到 5 级且企业、职业匹配的 T9 企业装 | 消耗 1 个订制模块，将 T9 改造为 T10 装备 | 生成 T10 装备、赋予初始随机效果，并永久绑定妮姬 | 否               |
| 洗词条        | T10 装备                                  | 使用“效果变更”                           | 重新抽取随机效果名称、栏位及随附数值            | 是，本任务范围   |
| 洗数值        | T10 装备                                  | 使用“重新设置数值”                       | 保持效果名称不变，只重新抽取数值                | 否，属于另一任务 |

判断标准：凡是改变装备强化等级和基础属性的操作，属于**装备强化**；使用“效果变更”重新抽取效果名称及栏位，属于**洗词条**；保持效果名称不变、只使用“重新设置数值”，属于**洗数值**。效果的 Tier 1~15 是数值档位，不是装备强化等级。T9 → T10 改造、洗词条和洗数值都会消耗订制模块，但共用材料不代表它们是同一个操作。

## 装备基础系统

- 部位：头 / 身 / 手 / 腿 共 4 个，每个妮姬每部位一件
- 职业限定：攻击 / 防御 / 辅助三类职业的装备互不通用
- 稀有度：R / SR / SSR，稀有度越高基础属性越高
- 阶级：T1 ~ T9；T9 后为"企业装"，分米西利斯（Missilis）、泰特拉（Tetra）、极乐净土（Elysion）、朝圣者（Pilgrim）四大企业，同企业穿戴有加成
- 装备强化：消耗强化材料提高装备强化等级，从而提高装备的基础属性；不会重随或改变 T10 装备的随机效果
- 普通装备（T1~T9）没有随机效果，效果只存在于 T10 装备

## 装备强化（不是洗词条）

装备强化是一条独立的成长线：

- 输入：装备强化材料，以及游戏界面要求的其他资源
- 改变：装备强化等级和装备基础属性
- 不改变：T10 装备效果的类型、栏位、数值档位以及锁定状态
- 关系：T9 企业装强化到 5 级是进行 T9 → T10 改造的前置条件；T10 装备仍可继续强化，但这仍然不属于洗词条

自动化边界：洗词条任务不得点击“装备强化”，也不得把装备强化等级作为是否接受效果变更结果的判断条件。若以后需要自动强化装备，应建立独立任务、独立预算与独立确认流程。

## T9 → T10 改造（不是洗词条）

解锁与前提：

- 通关普通主线 16-28，解锁特拦（Interception EX / Special Interception）
- 改造条件：T9 企业装（T9M）+ 企业/职业匹配 + 装备强化到 5 级 + 消耗 1 个订制模块

改造结果：

- T9 → T10，成为 T10 装备；之后可继续执行独立的装备强化
- 赋予 1~3 条随机效果；初始效果数值固定为 Tier 11
- 改造后装备永久绑定该妮姬，无法卸下/转移；原 T9M 被消耗

部位的 T9 → T10 改造优先顺序（Prydwen 口径）：攻击向为头 > 手 > 身 > 腿；依赖 HP 的妮姬为身 > 头 > 腿 > 手；依赖 DEF 的妮姬为腿 > 手 > 头 > 身。这个顺序只决定先改造哪一个部位，不是洗词条策略，也不是装备强化操作。

风险提示：T9 → T10 改造会永久绑定装备且不可逆。洗词条任务默认不执行该改造；如以后需要自动升 T10，应作为独立任务实现。

效果数值档位与稀有度：

- 每种效果有 15 个数值档位（Tier 1~15），档位越高数值越大；这不是装备强化等级
- 蓝字 = Tier 12/13/14（高值稀有）；黑字 = Tier 15（该效果最高档，约 1% 概率）
- 初次改造为 T10 时，已有效果的数值固定为 Tier 11；后续效果操作无保底
- 效果影响战力 CP：效果条数越多、总档位越高 CP 越高，优越代码伤害增加的权重更高

游戏内“概率情报”显示：显示至四舍五入后的小数点第 4 位。各个栏位的效果获得机率彼此独立，1 号栏位为 100%、2 号栏位为 50%、3 号栏位为 30%。栏位获得效果时，不同效果的获得机率为：优越代码伤害增加 10%、命中率增加 12%、最大装弹数增加 12%、攻击力增加 10%、蓄力伤害增加 12%、蓄力速度增加 12%、暴击率增加 12%、暴击伤害增加 10%、防御力增加 10%，合计 100%。同一件装备无法重复获得效果；因此第 2、3 号栏位会从剩余效果中按原权重重新归一化，不能简单地把每个栏位都当作独立的 10%/12%。

各个栏位的效果获得机率彼此独立：1 号栏位 100%，2 号栏位 50%，3 号栏位 30%。因此装备最终有 1 条、2 条、3 条效果的概率分别为 35%、50%、15%（1 号栏位必有；2、3 号栏位都可能不赋予效果）。效果变更时，未锁定栏位按同一规则重新抽取；锁定栏位不变。

效果数值档位的抽样概率为：T1~T5 各 12%（合计 60%），T6~T10 各 7%（合计 35%），T11~T15 各 1%（合计 5%）。初次改造为 T10 时，已有效果统一固定为 T11（例如优越代码伤害增加 23.56%、攻击力增加 11.81%、最大装弹数增加 68.93%）；之后使用“效果变更”或“重新设置数值”才进入随机档位池。T15 是 1% 的最高值；T12~T14 通常显示为蓝字，T15 为最高档黑字/白边效果，字色仍应以客户端实际显示为准。效果数值将在进入战斗时生效。

由此可用于后续任务的概率模型是：先按栏位是否赋予效果抽样，再在该栏位按剩余效果的权重抽样，最后按数值档位概率抽样；“效果变更”重新抽取效果类型与数值，“重新设置数值”只重新抽取数值档位。网上资料没有证明不同部位、职业或企业会使用不同的效果池，目前应按全装备共用一套效果池实现分析，待游戏内批量记录进一步验证。

## 效果变更与重新设置数值

前置条件：目标必须已经是 T10 装备。进入 T10 装备的效果操作界面后：

- 效果变更：重新抽取效果类型与数值（未赋予效果的栏位可能获得新效果）
- 重新设置数值：只重新抽取数值档位，效果类型不变，未赋予效果的栏位不会新增效果
- 每次效果变更或重新设置数值后都会显示“OPTION CHANGE”结果页；候选“变更效果”更符合目标时点击“效果变更”应用新结果，原“当前效果”更符合目标时点击“效果维持”放弃本次变更

自动化范围：当前 MDA 洗词条任务只点击“效果变更”，只按效果名称与栏位结构判断结果。全量扫描会读取数值并输出到日志/摘要，但数值 / Tier 不参与本次决策；“重新设置数值”以及数值 / Tier 门槛属于独立的洗数值任务，当前不得配置或点击。

## 效果锁定与成本

- 效果锁定：锁定后，被选中的效果保持不变；锁定时可在“订制模块”和“自订密钥”之间选择一种材料支付
- 订制模块锁定：选择订制模块后锁定效果，锁定状态持续到手动解除
- 自订密钥锁定：选择自订密钥后仅对 1 次效果变更或重新设置数值生效；22 章后可用

锁定成本（以截图中的游戏内界面为准）：

| 锁定前已有的效果锁定数量 | 订制模块（可选） | 自订密钥（可选） |
| ------------------------ | ---------------- | ---------------- |
| 0 → 1                    | 2                | 20               |
| 1 → 2                    | 3                | 30               |

上表是二选一的替代成本，不是两种材料同时消耗。截图已直接确认 0 → 1 的“订制模块 2 / 自订密钥 20”；1 → 2 的“订制模块 3 / 自订密钥 30”沿用已有资料，后续应再用游戏截图核对。效果锁定窗口中会显示“选择消耗材料”，并分别列出“必要”和“持有”数量；只有选中某一种材料后，底部“确认”按钮才可用。

效果变更或重新设置数值只能消耗订制模块，基础消耗按已锁定效果数量递增：0 条锁定时消耗 1 个订制模块，锁定 1 条时消耗 2 个，锁定 2 条时消耗 3 个。自订密钥只能支付锁定成本，不能代替上述效果操作成本。锁定 3 条后继续操作是否仍允许点击、以及实际消耗，应以客户端当前界面为准。

规律：每增加 1 条已锁定效果，单次效果变更或重新设置数值的订制模块消耗 +1（1 → 2 → 3）；锁定效果本身则从订制模块或自订密钥中二选一支付。

当前任务的材料策略：订制模块通常会先于自订密钥耗尽，且效果变更只能消耗订制模块。因此 MDA 在效果锁定时应高权重优先自订密钥，优先把订制模块保留给后续效果变更；只有自订密钥不足，或长期永久锁的整体收益足以抵消订制模块的高稀缺性时，才考虑用订制模块锁定。该条是本任务策略，不是游戏内强制规则。

## 外部攻略中的常见词条选择经验

本节只记录外部攻略中的常见经验，不作为 MDA 的最终调度算法。MDA 需要先扫描现有词条，再比较四件装备下一次操作的长期收益；完整策略与伪代码见[洗词条策略与 MDA 实现逻辑](洗词条策略与Agent逻辑.md)。

- 通常优先改善当前收益较低且较容易提升的部位，但不能只按当前分数固定排序
- 目标效果可按角色需求划分优先级；当前任务只判断效果名称，不设置数值门槛
- 常见单件套路：不锁定“效果变更”直到出现目标效果 → 锁定目标效果 → 再洗其余栏位；角色级任务不能照此连续洗完一件，而应在每次效果变更后重新比较四件装备
- 批量效果变更、避免过渡态、DPS 优先于辅助

## 材料来源与经济

- 特拦（16-28 后）：每次击杀 85% 概率额外奖励；订制模块约 26.67%，T9M 约 26.75%；200 个企业手臂部件可合成随机 T9M
- 异常拦截（22 章后）：提供自订密钥等
- 拦截模式每日 3 次挑战机会
- 订制模块和自订密钥都属于稀缺材料；任务需优先保留订制模块用于效果变更，并按两种库存与效果变更次数预算止损

## 对自动化任务的影响

洗词条任务本质是一个只处理 T10 装备“效果变更”的循环判定器：

1. 确认目标已经是 T10 装备；不是 T10 装备则停止，不进行装备强化或 T9 → T10 改造
2. 进入 T10 装备的效果操作界面
3. 读取当前效果的官方名称、数值、“未获得效果”栏位和锁定状态
4. 按效果名称、栏位规则和全局配额与目标清单比对
5. 只执行一次“效果变更”，不得点击“重新设置数值”
6. 比较结果页的“当前效果”和“变更效果”：候选更优则点击“效果变更”，当前效果更优则点击“效果维持”
7. 按下一步动作规划，在效果变更前执行需要的效果锁定；结果页处理后，自订密钥锁定失效，若继续洗则回到步骤 3
8. 受订制模块、自订密钥库存与效果变更次数预算约束，达到上限即停止

明确不属于本任务的操作：重新设置数值、按数值 / Tier 判断词条、提升装备强化等级、消耗强化材料、将 T9 企业装改造为 T10 装备、选择优先强化或优先升 T10 的部位。即使这些入口与效果变更位于相邻界面，也不得由洗词条任务触发。

落地前待确认事项：

- 客户端与 UI 文案：概率情报弹窗、T10 装备详情页、效果锁定弹窗和效果变更结果页的主要文案已根据截图确认；仍需识别“装备强化”入口作为禁止点击区域
- 目标配置：妮姬 → 目标效果名称、栏位规则、锁定策略、材料预算
- 识别方案：官方效果名称的 OCR、数值区域 OCR、“未获得效果”识别、锁定状态按槽位右侧 25% 区域像素颜色判定（蓝色=永久锁、橙色=一次性锁，不依赖模板）
- 风险控制：任务只允许“效果变更”；禁止“重新设置数值”、装备强化和 T9 → T10 改造，防止概念混淆与误操作；T9 → T10 改造不可逆
