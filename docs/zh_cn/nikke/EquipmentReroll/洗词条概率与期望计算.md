# NIKKE 洗词条概率与期望计算

> 效果重洗的目标是效果种类和数量，数值重洗的目标是现有效果的总 T。两者使用不同的续程估值和候选分布，不能把一个分支的判重假设直接套给另一个分支。本文效果模型于 2026-10-21 修正；数值模式的现有实现本次保持不变，其判重边界仍需单独验证。

## 效果重洗：重复规则与动态成本

[官方 2026-09-17 更新公告](https://nikke-en.com/newsdetail.html?content_id=599e7e8faa19da4f2eaa2d8a918a0cb40a0d)第 11.2 节明确：某个槽位生成与此前相同的效果和数值时，重新抽取的是数值；未获得效果的槽位仍可以再次为空。这并不排除旧效果种类或整组旧效果组合。

因此，效果模式直接按栏位出现率、效果权重和同件不重复规则枚举结果，不减去旧效果组合的概率，也不按 `1-P(整组重复)` 重新归一化。旧词条是 T1 还是 T15，不会改变下一次效果种类的分布。例如当前只有第 1 槽攻击，下次仍为“攻击、空、空”的概率为 `10% × 50% × 70% = 3.5%`。

固定锁集合不变、只等待一次完整达标时，每次成功概率为 p，每轮模组费为 c，首次达标期望为：

`E = c / p`

这只是**固定策略基线**。如果目标需要多个效果，实际流程可以先获得其中一个效果、锁定后再补齐其余效果；用“从头到尾保持当前锁集合、一次抽齐”的期望来评价整个任务，会遗漏这条更便宜的路径。例如追“优越、攻击、装弹”时，不能把无锁一次凑齐三种效果的 `1/p` 当作正常分阶段策略的平均耗材。

当前效果模式由 `effect_cost.go` 实现动态锁策略。每件最多两把锁，三个槽位中已获得且位置正确的需求效果均可参与新增锁的成本比较；保留已有永久锁，不自动解锁。每次新增固定锁按首锁 2、次锁 3 模组计入获取费，其后每轮重洗为 `1 + 活动锁数` 模组；已有永久锁的获取费视为沉没成本。

对给定锁态 L，设下一轮重洗前的续程成本为 `F(L)`，每轮模组费为 c；候选效果组合 x 出现后，`B(L,x)` 为立即达标或继续新增锁的最小成本。没有值得接受的候选时允许维持原结果，Bellman 方程为：

`F(L) = c + Σ P(x|L) × min(F(L), B(L,x))`

候选完整达标时 B 为 0；可新增锁时，B 包含该锁获取费及加锁后的动态成本。新增锁只递归到锁数更多的状态，最多两层；对候选 B 排序后可直接解出该阈值方程，无需假定一次凑齐全部目标。

2026-10-22 补充：禁止词条只阻止最终达标，不直接否决中间候选。若已有需求效果可通过加锁保留、禁止项尚未锁住，则模型将“保留需求后清除禁止项”一并计价。例如该件负责攻击与优越代码、禁止装弹，当前洗出“攻击@1、优越代码@2、装弹@3”：两把固定锁费用为 5，锁定后装弹在第 3 槽再次出现的概率为 `0.3 × 0.12 / (1 - 0.1 - 0.1) = 0.045`，其余效果或空槽均可结束。因此剩余模块期望为 `5 + 3 / (1 - 0.045) ≈ 8.14`，低于从三条无效效果重新追该目标的约 19.88。此前只枚举 2、3 槽的限制遗漏了这条路径。

若其余装备已提供全部配额，本件只需清除禁项，则无需保护本件多余的需求效果。若含禁候选的续程成本更高，仍维持原结果；禁止项永久锁定仍视为不可达。初始估算、候选取舍、加锁、已有锁核验和历史锁恢复共用同一计划口径。

模块口径中，已有一次性锁只保护本轮，结果出现后失效；后续如需永久保护同一效果，仍须支付新增永久锁费。密钥口径将密钥数量独立于模块计价，给出足量密钥持续续用时的**模块成本下界**；实际库存不足时改用模块口径重新规划。任务开始时的材料预估统一使用不依赖密钥的模块口径，不将未知或有限密钥库存算成无限免费锁。

角色模式由 `quota_cost.go` 用配额分配 DP，在每件最多承担三种效果的约束内，精确最小化当前快照下四件局部动态成本之和；不会让各件重复承担同一份稀缺配额。接受新结果后重新分配各件责任。这里“精确”仅指分配目标本身：局部动态策略与当前分配的组合仍是分解估值，并非四件随机过程、未来配额交换、有限密钥库存和现有调度策略的全局最优解。

界面的“预计”属于完成目标的续程估值，不是保底，也不能仅通过把 942 改成某个固定倍数修正。

`reroll_probability.go` 负责效果分布和固定锁基线。`effect_probability_rules_test.go` 验证旧效果组合仍可重现、概率不随旧数值档位变化、锁定效果仍从其他槽的抽取池排除，以及固定锁的几何期望。动态策略另有对应回归测试。

## 数值重洗：成本估值与候选取舍

> 本节记录数值分支的现有实现。本次效果成本修复不修改它的 `tierProbabilities`、候选枚举和整组重复条件化。上述官方逐槽重抽数值规则对数值分支的具体影响，需要另建逐槽回放与独立概率验证；以下实现说明不代表已完成这项规则核验。

每轮对每件装备枚举所有合法三槽状态：不锁、固定锁、单次锁（最多两把）；允许免费解除已有锁、将单次锁改固定锁或反向替换。先解除不需要的锁，再新增固定锁、单次锁，以模组优先的成本口径安排混合锁顺序。

先计算续程估值 `V`：逐种目标效果，使用背包 DP 在范围内的装备之间分配所需总 T。每件可以免费保留现值，也可以选择更高门槛；提升成本按“补齐其他目标词条的固定锁费用 + 每轮模组费 / 达到门槛的概率”估算。固定锁已有费用视为沉没成本；本轮单次锁结果后过期，不计作未来免费保护。单件模式使用同一算法，只包含指定装备。

各效果的最小补齐成本相加得到 `V`。这是**保守的分解估值**：未来按独立抽样且达到门槛才接受建模，未利用超出门槛的随机富余，也未联合摊销跨效果的锁定费用；不等同于实际最终耗材预测或四件十二槽的全局最优解。未来续程以固定锁为基线，不把密钥人为兑换成模组，也不重复向各效果分配同一份密钥库存。

实际下一轮对每个装备、每个可支付锁方案枚举最多 `15^3` 个完整候选，使用与结果页相同的接受准则，并精确排除整组重复。方案统计与排序为：

- `Probability`：下一轮接受概率 p。
- `ExpectedModules`：保持当前方案直到首次接受所需的模组期望，含新增固定锁费用；已有固定锁不重付。
- `RemainingModules`：接受后的平均续程估值 V。
- `ExpectedTotalModules`：上述两项之和，作为主排序；相同再比较密钥消耗、锁变更数量。不再比较“每有效 T 的模组成本”。
- 单次锁每轮支付密钥；库存只能支持 n 轮时，以 `(1-p)^n` 计算未接受就耗尽密钥的分支。该分支估算转固定锁费用，并重新计算转锁后的接受概率与续程成本，不能只追加转换费。
- 每轮实际费用与冻结方案的首轮模组/密钥总量必须一致，并核对已知库存；不一致则停止，不能按估算扣费。

这是**首次接受期望 + 续程估值的滚动规划**。每次接受后重新分配角色目标，不固定平均分摊，也不承诺全局最少材料。锁方案的首轮可支付不代表库存足以完成全部目标，后续仍可能因材料不足停止。未知库存先用现有乐观模型选装，锁定页取得真实库存；若冻结方案已无法支付则停止，不偷偷改材料。统计中的密钥耗尽转锁只用于估值，执行层每轮重新规划，不擅自执行预估的未来操作。

### 候选接受规则

比较保留旧结果与接受候选之后完成全部目标的 V。候选严格更低则接受；成本相同时，只有截断总进度 `Σ min(效果总T, 目标总T)` 增加才接受。成本和进度都相同则维持，避免反复交换。每种效果都通过补齐目标的耗材估值衡量，没有人工设置攻击或装弹的价值权重。

允许某一目标退步来换取整体成本下降；不再让装弹降低一档否决攻击或优越代码的大幅提升。也不是三条 T 简单相加：即使总 T 增长，续程成本恶化仍拒绝。未选效果不参与估值，但仍参与整组重复概率。效果种类/空槽不能变化，受保护槽的档位不能变化，候选值必须能校准到官方档位。

执行流程与验证范围见[洗词条数值实现](洗词条数值实现.md)。例如候选让效果 A 上升、效果 B 下降，是否接受取决于全部目标的续程成本；仅凭两项档位的增减不能下结论。

## 效果重洗：基础概率与固定策略参考

> 以下维护 NIKKE T10 装备“效果变更”的基础概率参考与明确指定策略下的计算。无需额外排除旧效果组合；示例策略不等同于当前全部调度与锁定决策的精确平均耗材。
> 策略语义以[洗词条策略与Agent逻辑](洗词条策略与Agent逻辑.md)为准，游戏内概率/UI 原始依据见[装备系统与洗词条研究](装备系统与洗词条研究.md)。

- 整理日期：2026-10-21
- 状态：概率模型与研究文档一致；期望计算为理论基线，实际客户端若有调整需同步更新本文
- 概率依据：游戏内“概率情报”原文明确说明“效果无法重复获得，计算机率时排除已获得的效果，变动概率为显示机率/(100%-排除的效果机率总和)”；本文基础概率与期望计算按此规则建模。

## 1. 概率模型

### 1.1 栏位效果获得概率

效果变更时，未锁定栏位按以下概率独立决定是否赋予效果：

| 栏位 | 获得效果概率 |
| ---- | -----------: |
| 1 号 |         100% |
| 2 号 |          50% |
| 3 号 |          30% |

因此一次效果变更后，装备最终词条数量分布为：

| 词条数量 | 概率 |
| -------- | ---: |
| 1 条     |  35% |
| 2 条     |  50% |
| 3 条     |  15% |

### 1.2 效果权重

栏位获得效果时，各效果按以下权重抽取：

| 效果             | 权重 |
| ---------------- | ---: |
| 优越代码伤害增加 |  10% |
| 命中率增加       |  12% |
| 最大装弹数增加   |  12% |
| 攻击力增加       |  10% |
| 蓄力伤害增加     |  12% |
| 蓄力速度增加     |  12% |
| 暴击率增加       |  12% |
| 暴击伤害增加     |  10% |
| 防御力增加       |  10% |

### 1.3 同件不重复与剩余权重归一化

游戏内“概率情报”原文：

> 不同效果的获得机率
> 栏位获得效果时，各个效果获得机率如下：点击效果可查看各个效果数值的具体机率。效果无法重复获得，计算机率时排除已获得的效果。此时的变动机率为「显示机率/(100%-排除的效果机率总和)」

即：效果无法重复获得，计算某个效果的实际获得概率时，先排除“已获得的效果”，再按上述公式归一化。

这里的“已获得的效果”分两类：

- **本次效果变更结果中已抽到的效果**：在后续栏位的抽取池中排除（同一结果内不重复）；
- **未锁定的旧效果**：不参与排除。旧效果被替换后已离开该装备，可能重新落回本格（实测见下例）：

```text
当前效果：  【蓄力速度增加】【最大装弹数增加】【未获得效果】
变更效果：  【蓄力速度增加】【暴击率增加】【命中率增加】
```

当前已有的“蓄力速度增加”在变更结果中再次出现，说明**未锁定**旧效果被替换后不占用新结果的效果池；只有本次结果内部已抽到的效果参与后续排除。

- **已锁定的效果**：在变更后仍留在该装备上，已占用该效果的“唯一名额”，因此会在其余槽位的抽取池中被排除——同一件装备永远不可能有两条相同效果（已锁了一条攻击，就不可能再洗出另一条攻击；要“两条装弹”必须落在两件不同装备上）。

本文期望计算按上述规则建模：采用“1 → 2 → 3 号栏位顺序抽取，每次抽取时排除已抽到的效果，并以显示机率/(100%-排除效果机率总和)作为变动机率”。该模型算出的“至少出现优越代码”= 18.15%、“至少出现优越代码或攻击力”= 34.17%，与本文第 2 节基础概率参考表一致。

### 1.4 数值档位抽样概率

效果数值档位抽样概率为：

- T1~T5：各 12%（合计 60%）
- T6~T10：各 7%（合计 35%）
- T11~T15：各 1%（合计 5%）

初次改造为 T10 时，已有效果统一固定为 T11；之后的效果变更或重新设置数值进入随机档位池。

## 3. 期望订制模组消耗

### 3.1 四优（4 有效）

**场景：** 一开始 0 个有效词条，四件装备各洗出至少 1 条“优越代码伤害增加”。

**策略：** 任意栏位出现优越代码即接受并结束该件；不锁定；每次效果变更消耗 1 个订制模组。

**计算：**

- 单次效果变更至少命中 1 条优越代码的概率：

\[
p = 18.15\% = 0.1815
\]

- 单件装备所需效果变更次数服从几何分布：

\[
E[\text{次数}] = \frac{1}{p} = \frac{1}{0.1815} \approx 5.5096
\]

- 四件装备独立，总期望次数：

\[
4 \times 5.5096 \approx 22.0386
\]

- 每次消耗 1 个订制模组，因此：

\[
\text{四优期望订制模组消耗} \approx 22.04 \text{ 个}
\]

> 该结果按 1.3 的游戏原文排除规则计算。

### 3.2 示例：攻 4 + 优 4（每件同需攻优）

**场景：** 一开始 0 个有效词条，四件装备各洗出 1 条“优越代码伤害增加”和 1 条“攻击力增加”。

**策略（与《洗词条策略与Agent逻辑》一致）：**

1. 0 目标状态不锁，每次效果变更消耗 **1 模组**；
2. 若 2/3 号槽出现 1 个目标（攻或优），接受并锁定该槽；若只出现在 1 号槽，按“1 号单目标不锁、维持丢弃”处理；
3. 锁定后追另一个目标，每次效果变更消耗 **2 模组**（1 锁）；
4. 若直接同时出现攻+优，则完成。

**口径：** 锁定材料视为免费（自订密钥锁定，不消耗订制模组）；但锁定存在导致的效果变更费用上升仍计入。

**无锁状态（0 目标）单次效果变更的转移概率：**

| 结果                          |   概率 |
| ----------------------------- | -----: |
| 直接双目标完成                |  2.13% |
| 仅 2 号槽单目标 → 锁 2        |  8.69% |
| 仅 3 号槽单目标 → 锁 3        |  5.12% |
| 无推进（含 1 号单目标被维持） | 84.05% |

**锁定后追另一个目标：**

| 锁定位置 | 单次命中另一目标概率 | 锁定阶段期望消耗 |
| -------- | -------------------: | ---------------: |
| 锁 2 号  |               10.06% |    约 19.89 模组 |
| 锁 3 号  |               10.10% |    约 19.81 模组 |

锁定阶段每次效果变更消耗 2 模组，因此：

\[
E\_{\text{锁2}} = \frac{2}{0.1006} \approx 19.89
\]

\[
E\_{\text{锁3}} = \frac{2}{0.1010} \approx 19.81
\]

**单件期望：**

\[
E*{\text{单件}} = \frac{1 + P(\text{锁2}) \times E*{\text{锁2}} + P(\text{锁3}) \times E\_{\text{锁3}}}{1 - P(\text{无推进})}
\]

代入：

\[
E\_{\text{单件}} = \frac{1 + 0.0869 \times 19.89 + 0.0512 \times 19.81}{1 - 0.8405}
\approx 23.48
\]

**四件合计：**

\[
E\_{\text{四件}} = 4 \times 23.48 \approx 93.90
\]

即：

> **攻 4 + 优 4 配额期望订制模组消耗约为 93.90 个，约等于 94 个。**

> 该结果按 1.3 的游戏原文排除规则计算。

### 3.3 自定义配额（1~12 有效）中的锁定后概率示例

以下示例用于说明 3 号栏位核心词条价值，具体概率会随剩余全局配额和已锁效果变化：

- 锁定 3 栏“优越代码伤害增加”后，下一次在 1、2 栏同时得到“攻击力增加 + 任一补充词条”的基线概率约为 **3.38%**；
- 锁定 3 栏“最大装弹数增加”后，下一次在 1、2 栏同时得到“优越代码伤害增加 + 攻击力增加”的概率约为 **1.46%**。

## 4. 模型校验

- 按 1.1~1.3 的概率模型，单次效果变更“至少出现优越代码或攻击力”的概率约为 **34.17%**，与基础概率参考表一致；
- 单独“至少出现优越代码”的概率约为 **18.15%**，与基础概率参考表一致；
- 攻 4 + 优 4 期望计算中的状态转移概率、锁定后命中概率均由同一模型推出。
