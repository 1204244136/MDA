## 一句话结论

NIKKE 的核心战斗机制是**爆裂系统**（Burst System）：每个妮姬的"大招"属于爆裂阶段 I / II / III 之一，战斗中全队共享一个**爆裂槽**，攻击命中积攒能量，槽满后按 **I → II → III 的固定顺序**依次释放爆裂技能，三连成链后触发持续约 **10 秒的全爆裂（Full Burst）** 高伤窗口。因此队伍必须覆盖全部三个阶段才能完成爆裂链条；配队、战斗节奏乃至自动化任务的核心都围绕"如何稳定、高频地打出全爆裂"展开。

## 概念边界

以下概念互不相同，后续设计任务与讨论时必须分别区分：

| 概念     | 触发/时机                           | 主要作用                               | 备注                                         |
| -------- | ----------------------------------- | -------------------------------------- | -------------------------------------------- |
| 爆裂技能 | 爆裂槽满后，按阶段顺序手动/自动释放 | 每个妮姬的大招（增益、减益或爆发输出） | 技能冷却 20 / 40 / 60 秒不等                 |
| 爆裂槽   | 全队攻击命中敌人时持续积攒          | 决定能否进入"爆裂时间"                 | 全队共享，积攒速度与武器相关                 |
| 爆裂时间 | 爆裂槽满后的一段可操作窗口          | 窗口内依次选择 I、II、III 释放爆裂技能 | 一轮爆发最多释放 3 个大招                    |
| 爆裂阶段 | 妮姬自带属性                        | 决定其在链条中的释放顺序与定位         | I（开局增益）→ II（桥梁辅助）→ III（主输出） |
| 全爆裂   | I、II、III 依次释放完毕后触发       | 约 10 秒的集火/输出窗口，伤害显著提升  | 3 号位在链条最后，吃满全部加成               |
| 爆裂冷却 | 爆裂技能释放后的冷却时间            | 决定同一阶段能多久再次上场             | 20 秒约每轮可用，40 秒隔轮，60 秒慢速重炮    |

判断标准：凡是"攒槽—放招—成链—全爆裂"这一条链路上的概念都属于爆裂系统；而属性克制、武器射程等虽然影响爆裂节奏，属于独立的战斗维度，建模时需分开。

## 爆裂系统基础

### 爆裂技能分级

- 每个妮姬的爆裂技能固定属于 **I、II、III 三个阶段之一**，无法更改。
- 阶段定位：I 通常负责团队增益与爆裂能量生成（链条起点）；II 负责进一步增益/减益/承伤（桥梁）；III 几乎总是主输出位（链条终点，吃满前两段加成）。
- 爆裂技能会随技能等级成长，**技能等级投入常比抽新角色收益更大**。

### 爆裂槽（Burst Gauge）

- 全队共享一条能量条，队伍造成武器伤害时积攒；槽满后进入"爆裂时间"。
- 积攒速度受**武器类型**影响明显（见下文"爆裂积攒效率"），也与命中与否有关。
- 没有足够的能量生成时，槽涨得慢，全爆裂覆盖率会大幅下降——"攒爆裂能量"型角色（多为 I 阶段）是队伍里被低估的关键一环。

### 爆裂链条（Chain）

- 爆裂时间内的释放顺序**强制为 I → II → III，不可跳级**。
- 缺少 I 或缺少 III，链条直接断裂，永远打不出全爆裂。
- 一轮爆发中 5 人最多只能放 3 个大招（每阶段一个）；同一阶段若有多个角色，通常自动模式下会选**最左侧**那个先放（因此站位有意义）。

### 全爆裂（Full Burst）

- I、II、III 依次放完即触发，持续约 **10 秒**。
- 效果：全员（AI 队友）聚焦当前目标，并获得显著伤害增益；敌方受击伤害提升。
- 这是全队输出的核心窗口，配队与操作的目标都是"每轮循环稳定进入全爆裂、避免空转回合"。

## 冷却时间（Cooldown）

- 爆裂技能冷却普遍为 **20 / 40 / 60 秒** 三档，是配队中最重要的数值。
- 20 秒：基本每轮循环都能放，负责维持链条运转。
- 40 秒：隔一轮才能再放，通常需要第二个同阶段角色补位（即"同阶段覆盖 CD"）。
- 60 秒：慢速重炮，属于围绕它构建整队的核心单位。
- 常见错误：3 个角色都是 40 秒档，导致每隔一轮就有一个阶段空缺。正确做法是**混搭冷却**，保证每轮都有可用的 I、II、III。

## 爆裂积攒效率

- 武器类型影响爆裂槽积攒速度，从快到慢大致为：
  **火箭筒（弹夹装填型）＞ 霰弹枪（弹夹装填型）＞ 狙击步枪 ＞＞ 冲锋枪 / 机枪**。
- 射程（准心变蓝的"甜蜜点"）也影响命中与积攒：霰弹枪 0-25、冲锋枪 15-35、突击步枪 25-45、机枪 35-55、狙击步枪 45-100；火箭筒无视射程。
- 对自动化任务的意义：如果未来要做"战斗内自动打爆裂节奏"，需关注队伍武器构成与命中情况，而非只看爆裂技能本身。

## 配队规则

- **铁律：队伍必须同时覆盖 I、II、III 三个阶段**，缺一即无法全爆裂。
- 常见模板框架："1-2-3" 或 "3-2-1" 描述的是队伍的阶段布局，具体为：
    - 3 号位（主输出，核心输出手）× 1，首选——它是队伍存在的理由
    - 1 号位（增益 + 攒能量）× 1，启动链条、维持爆裂槽
    - 2 号位（增益/破甲/装填蓄力等增幅）× 1，放大主输出
    - 剩余两格：生存位（治疗/护盾）+ 弹性位（二段输出 / 补 CD 缺口 / 第二 3 号位）
- **双 3 号位**是推图主流：3 号位多为 40 秒 CD，一轮技能轴约 20 多秒，只带一个 3 号位会隔轮空转；带两个 3 号位可保证每轮都能进全爆裂。
- **减 CD 角色**（如丽塔 / 沃纶姆 / 朵拉）：可减少大招 CD，配合手动关掉 Auto 等待几秒，即使只带一个 3 号位也能每轮打满。
- 站位：自动模式下同阶段先放最左侧角色，合理站位可控制哪个角色先开爆裂。

## 元素克制（Code）

- 单位与敌人各有 5 种 Code：**火（Fire）、水（Water）、风（Wind）、铁（Iron）、电（Electric）**。
- 对敌人弱点属性攻击获得 **10% 伤害加成**；被克制则受到 +10% 伤害（我方输出不变）。
- 高难内容中值得为主 C 备好每个属性的 3 号位输出手。
- 原则：**不要为强行凑属性而牺牲爆裂循环**——能稳定全爆裂的"错属性"队伍，通常胜过"属性正确却空转"的队伍。

## 常见误区

1. **缺 I 或缺 III**：链条断裂，永远打不出全爆裂。
2. **冷却打架**：多角色抢同一冷却窗口，隔轮就缺一个阶段。
3. **爆裂能量生成不足**：槽涨得慢，即使主 C 很强，全爆裂覆盖率也上不去。
4. **重属性轻循环**：属性错误不可怕，爆裂空转才致命。
5. **忽视技能等级**：核心循环角色的爆裂技能升级，常比抽新角色收益更大。

## 面向 MDA 自动化的初步观察

> 本节为资料阶段的推断，**未经游戏内截图/UI 核对**，需后续实测后再落实为识别与操作设计：

- 战斗界面通常存在爆裂槽/爆裂时间的可视元素（满槽提示、阶段按钮、倒计时窗口），是判断"是否可开爆裂 / 处于哪一阶段"的候选识别点。
- 爆裂技能通常通过屏幕侧边的角色头像按钮释放；自动模式由游戏自动按最左侧顺序释放。
- 若任务目标是"自动按节奏打爆裂"，可考虑：识别爆裂槽满/爆裂时间窗口 → 按 I→II→III 顺序点击对应角色头像 → 判定全爆裂是否进入 → 等下一轮。状态机建模时，把"攒槽中 / 爆裂时间(可放I) / 待放II / 待放III / 全爆裂中 / 冷却中"作为独立状态。
- 上述 UI 细节与坐标需在实机截图后确认，本阶段不做结论性设计。
