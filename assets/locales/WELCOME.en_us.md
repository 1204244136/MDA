# MDA Announcements

## PC Setup

The PC version of MDA currently **only supports the AAA control mode**. Before using it, install the **Interception driver** and select **AAA** in the connection settings.

You can get the Interception installer from our [QQ user group (584275905)](https://qm.qq.com/q/JpBdw9s4Ei).

## Android Beta Testing

**MDA for Android is in beta testing. Join our [QQ user group (584275905)](https://qm.qq.com/q/JpBdw9s4Ei) to take part!**
